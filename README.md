# 📊 Sales Analysis -2026- Dashboard

## 📌 Project Overview

An interactive **Sales Analysis Dashboard** designed to evaluate retail performance, sales channel efficiency, and geographical product demand. 
The dashboard translates raw transaction data into clear financial KPIs and dynamic visual reports, empowering decision-makers to track revenue growth, profit margins, and inventory performance.

## 🎯 Core Features & Analytical Insights

* 📅 **Time-Series Analysis:** Monthly seasonality trends comparing **Total Revenue vs. Total Gross Profit** across 2026 quarters.

* 🌍 **Geographical Mapping:** Spatial heatmap visualizing **Revenue by Country** across European markets (Spain, Sweden, Switzerland, UK, etc.).

* 🛒 **Category & Channel Breakdowns:**

  * **Revenue vs. COGS by Category:** Performance analysis across product lines (*Camping, Hiking, Travel, Cycling, Fitness*).

  * **Sales Channel Comparison:** Breakdown of sales streams across *Online Store, Corporate, Retail Partners,* and *Marketplace*.

* 🔝 **Top Products Ranking:** Identification of top 5 items by volume (e.g., *Trail Boots, Summit Backpack 45L, Compact Sleeping Bag*).

* 🎛️ **Dynamic Slicers:** Instant filtering by **Order Date**, **Customer Type** (*Business, New, Returning*), **Sales Channel**, and **Country**.
* 

## 🛠️ Tools & Technologies Used

* **Microsoft Excel:** Power Query, Pivot Tables, and visual design.

* **Data Visualization:** Line charts, Column comparisons, Horizontal bar charts, and Map visualization.

* **Design:** Dark & Light theme layout with intuitive navigation buttons (*Data, Analyze, Dashboard*).
